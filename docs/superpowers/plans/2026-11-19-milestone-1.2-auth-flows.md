## Verified Better Auth v1.7.25 API Reference

### Email Verification (core — not a plugin)
- **Config key:** `emailVerification.sendVerificationEmail: async ({ user, url, token }, request) => void`
- **Config key:** `emailVerification.autoSignInAfterVerification?: boolean`
- **Server endpoint (resend):** `POST /api/auth/send-verification-email` body `{ email, callbackURL? }`
- **Client method:** `authClient.sendVerificationEmail({ email, callbackURL })`
- **Sign-in enforcement:** `emailAndPassword.requireEmailVerification: true` → server returns `EMAIL_NOT_VERIFIED` error code
- **Token URL shape:** `${baseURL}/api/auth/verify-email?token=TOKEN&callbackURL=URL`
- **Verify endpoint:** `GET /api/auth/verify-email?token=TOKEN` (already handled by Better Auth router)

### Sign-in (email/password)
- **Client method:** `authClient.signIn.email({ email, password, callbackURL?, rememberMe? })`
- **Returns:** `{ data: { token, user } | null, error: { code, message } | null }`
- **Error codes:** `INVALID_EMAIL_OR_PASSWORD`, `EMAIL_NOT_VERIFIED`

### Sign-in (Google OAuth)
- **Client method:** `authClient.signIn.social({ provider: "google", callbackURL: "/" })`
- **Already conditionally configured** in `src/lib/auth.ts`

### Password Reset
- **Config key:** `emailAndPassword.sendResetPassword: async ({ user, url, token }, request) => void`
- **Config key:** `emailAndPassword.resetPasswordTokenExpiresIn?: number` (default 3600s)
- **Server endpoint (request):** `POST /api/auth/request-password-reset` body `{ email, redirectTo? }`
- **Server endpoint (callback):** `GET /api/auth/reset-password/:token?callbackURL=URL` → redirects to `callbackURL?token=TOKEN`
- **Server endpoint (complete):** `POST /api/auth/reset-password` body `{ newPassword, token? }` or query `?token=`
- **Client method (request):** `authClient.requestPasswordReset({ email, redirectTo })`
- **Client method (complete):** `authClient.resetPassword({ newPassword, token })`
- **Anti-enumeration:** Built into server — always returns same response whether email exists or not.
- **Error codes on complete:** `INVALID_TOKEN` (expired or not found)

## Tasks

### Task A — Email Delivery Abstraction
**Files created:**
- `src/lib/email.ts`

**Tests created:**
- `src/lib/__tests__/email.test.ts`

**Description:**  
Create a typed `sendEmail()` function that provides a safe interface for all auth-email sends. In development/test it logs the message; in production it throws unless `EMAIL_PROVIDER` is configured. This guards against accidentally sending real emails and makes future provider swaps (Resend, SendGrid) a one-file change.

```typescript
// Interface
export interface EmailPayload {
  to: string;
  subject: string;
  html: string;
}

// In production, throws unless EMAIL_PROVIDER is set.
// In dev/test, logs and returns without sending.
export async function sendEmail(payload: EmailPayload): Promise<void>
```

**Environment variables needed (`.env.local` only, never committed):**
- `EMAIL_FROM` — sender address (e.g. `"App Name <noreply@example.com>"`)
- `EMAIL_PROVIDER` — optional; `"stub"` (default) | `"resend"` | future providers

**Tests:**
- [ ] In test env: `sendEmail()` resolves without throwing.
- [ ] In test env: does not make network requests.
- [ ] In production env stub: throws if `EMAIL_PROVIDER` unset.
