## 1. Audit Findings (Confirmed Violations vs. Potential / Manual Items)

Severity scale:
- **Critical:** Blocks keyboard/screen-reader users from completing or escaping core workflows, or fails fundamental dialog/contrast/semantic requirements.
- **High:** Fails WCAG 2.1 AA success criteria across core pages/controls (contrast, missing ARIA relationships, broken tab/listbox keyboard model, touch targets < 44px on mobile).
- **Medium:** Heading hierarchy gaps, missing `scope="col"` / `aria-sort` / `aria-current`, missing `aria-hidden` on decorative icons, missing `role="alert"`/`role="status"` on secondary feedback banners.
- **Low:** Minor instruction associations (`aria-describedby` on character counters), redundant `title` tooltips, or polish items.
